
# Linux Foundation Kubernetes and Cloud Native Associate (KCNA) Certification Exam Guide

[![Linux Foundation KCNA](https://img.shields.io/badge/Linux%20Foundation-KCNA-003366?style=for-the-badge)](https://training.linuxfoundation.org/certification/kubernetes-cloud-native-associate/)
[![Level: Beginner](https://img.shields.io/badge/Level-Beginner-2E6DA4?style=for-the-badge)](https://training.linuxfoundation.org/certification/kubernetes-cloud-native-associate/)

A dedicated study guide and cloud-native reference repository for candidates preparing for the **Linux Foundation Kubernetes and Cloud Native Associate (KCNA) Certification Exam**.

---

## Exam Overview

The KCNA certification validates foundational knowledge of Kubernetes, container orchestration, and the wider cloud-native ecosystem, helping candidates build a foundation for further cloud-native learning.

- **Exam Format**: Online, proctored, multiple-choice exam
- **Target Audience**: Aspiring cloud-native professionals, developers, operations practitioners, and IT learners
- **Prerequisites**: None

---

## Core Exam Domains & Knowledge Areas

### 1. Kubernetes Fundamentals

- Kubernetes core concepts, components, and architecture.
- Basic administration, scheduling, and workload placement.
- Containerization concepts and container technologies.

### 2. Container Orchestration

- Kubernetes networking, connectivity, and service concepts.
- Security fundamentals and container orchestration practices.
- Storage concepts and troubleshooting common issues.

### 3. Cloud Native Application Delivery

- Cloud-native application delivery concepts and workflows.
- Deploying and managing containerized applications.
- Debugging application delivery and deployment issues.

### 4. Cloud Native Architecture

- Observability concepts, including metrics, logs, and traces.
- Cloud-native ecosystem projects, principles, and architecture.
- CNCF community, open-source collaboration, and cloud-native technologies.

## Recommended Practice & Study Resources

Combine official learning materials with supplementary study resources and practical exercises to strengthen your Kubernetes and cloud-native knowledge.

- **Official Linux Foundation Resources**: Review the [KCNA certification page](https://training.linuxfoundation.org/certification/kubernetes-cloud-native-associate/), its examination guide, curriculum, and recommended learning path.
- **CertsGate**: Explore supplementary [KCNA certification preparation resources](https://certsgate.com/exams/linux-foundation/kcna), including study materials and practice questions to help review core concepts.
- **Practical Kubernetes Study**: Use the [Kubernetes documentation](https://kubernetes.io/docs/home/) and [CNCF curriculum](https://github.com/cncf/curriculum/blob/master/kcna/README.md) while practicing basic workloads, networking, storage, and troubleshooting in a learning cluster.
